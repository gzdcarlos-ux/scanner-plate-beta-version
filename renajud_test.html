Teste de Arquitetura — Providers

Mesma lógica em camadas do app Flutter: Mock → Local → Remoto

Providers ativos (ordem de tentativa)

Espelha exatamente a ordem do RenajudService em Dart: só passa para o próximo provider se o anterior responder "não encontrado".

Base local simulada (equivalente à planilha .xlsx importada)

Formato: PLACA;observação — uma por linha. Isso simula exatamente o resultado da importação do .xlsx feita no app (coluna A = placa, coluna B = observação).

Config do provider remoto

Preencha no <script> abaixo (constante REMOTE_API_CONFIG) a URL e o token da API paga que você contratar (Infosimples, Apify "brasildados" etc.). Aqui é só a interface de teste.

Aceita formato antigo (ABC-1234) e Mercosul (ABC1D23).

Ferramenta de teste local — não persiste nem envia dados a nenhum servidor,
exceto se você ativar e configurar o provider remoto.
